# Font Lab Web — Prototype 0.1

ブラウザ上で既存フォントを読み込み、収録グリフの一覧、選択文字のプレビュー、試し打ち、編集設定のJSON保存・読込を行う初期プロトタイプです。

## 起動方法
1. `index.html`、`styles.css`、`app.js` を同じフォルダに置いたままにします。
2. `index.html` を最新のChrome / Edge / Firefoxで開きます。
3. フォント読み込みボタンから `.ttf` または `.otf` を選びます。

`opentype.js` はCDNから読み込むため、初回利用時はインターネット接続が必要です。完全オフライン化する場合は、ライブラリをローカルに同梱する構成に変更してください。

## 現在実装済み
- TTF / OTFなどのフォント解析（opentype.jsが解析できる形式）
- グリフ一覧、検索、カテゴリフィルター
- 選択グリフのブラウザプレビュー
- テキスト試し打ち
- 選択文字のプレビュー変形（横・縦スケール、傾き、見かけの太さ）
- ドット風の簡易プレビュー効果
- JSON形式で編集設定を保存・読込

## まだ未実装
- 輪郭点・ベジェ曲線を直接編集するエディター
- 一括加工を実際のグリフ輪郭へ適用する処理
- TTF / OTFの再構築・書き出し
- OpenType機能、カーニング、縦書き、異体字などを保持した完全な再構築
- JSONプロジェクトへの元フォントデータ埋め込み

JSONプロジェクトは編集設定のみを保存します。元のフォントファイルは別途保管し、再開時は必要に応じて同じフォントを読み込んでください。プレビュー変形は元フォントの輪郭を変更しません。

## 注意
フォントファイルのライセンスに従って利用してください。フォントのアップロードは行わず、ブラウザ内で処理します。
